v1.0.0
- Initial release of Multi Item Frame, supporting Forge 1.20.1 and NeoForge 1.21.1.
- Added Multi Item Frame in six sizes: 1x1, 1x2, 2x1, 1-and-2, 2-and-1, and 2x2, each craftable from vanilla Item Frames plus Redstone Dust, and convertible between adjacent sizes by crafting them together.
- Added a Glowing variant of every size, crafted from the corresponding non-glowing frame plus Glowstone Dust.
- Right-clicking a frame opens a settings screen where you can place items into each slot, toggle the frame's background visibility, and configure a highlight (frame or fill) with a chosen dye color per slot.
- Added optional integration with Applied Energistics 2's Memory Card and Mekanism's Configuration Card, letting you copy a frame's full settings and paste them onto another frame.
- Added optional JEI integration: items drag straight into frame slots, and dyes can be dragged directly onto a slot's color button to set its highlight color.
